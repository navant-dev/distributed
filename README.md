# Distributed Systems Simplified

A visual field guide that explains distributed-systems concepts for software engineers through concise, memorable one-pagers.

## Concepts

- Replication
- Consistency
- Partitioning
- Consensus
- Caching
- Queues

## Local development

Requires Node.js 22 or newer.

```bash
npm ci
npm run dev
```

Run `npm run build` to create a static export in `out/`.

## Hosting

The site is deployed to GitHub Pages by `.github/workflows/deploy-pages.yml` after changes reach `main`.
